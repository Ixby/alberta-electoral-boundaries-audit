# 2021 Census Profile extract, Alberta dissemination areas

`alberta_da_profile.csv`: 6,203 dissemination areas with the fields listed in `findings/referendum_electors/census_eligibility.py` (FIELDS). Built from Statistics Canada's Census Profile API, dataflow `STC_CP:DF_DA`, one request per characteristic, all genders, counts: `https://api.statcan.gc.ca/census-recensement/profile/sdmx/rest/data/STC_CP,DF_DA/A5..1.<CHARACTERISTIC>.1`, filtered to Alberta (`2021S051248*`).
