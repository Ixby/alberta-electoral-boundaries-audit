## What the audit actually found (the grounding floor)

The audit runs three *formal* signature tests with explicit criteria (§5.3.4 summary):

| Signature | Criteria | Minority result | Where |
|---|---|---|---|
| **Packing** (Calgary Zone A) | P1 size / P2 margin / P3 seat-loss | **Detected** | §5.3.1 |
| **Cracking** | C1 split / C2 minority-in-each / C3 single-district-feasible | **Airdrie detected; Cochrane "cracking-adjacent" (C3 fails)** | §5.3.2 |
| **Engineered boundary** | E1 negligible-pop / E2 alt-over-park / E3 no C-of-I | **RMH–Banff Park detected (Reading B)** | §5.3.3 |

Two things this constrains:
- **Packing is a *zone* finding (Calgary NW / Zone A), not a single flag pin.** No individual flag
  *is* "the packing." The closest flags geographically sit inside Zone A but the packing claim is
  about the zone's district sizing, not any one boundary.
- **The minority *passed* the adjacency pack-and-drain test** (§5.3.5); it achieves the effect via
  **hybridization** (city-splitting that internalizes packing/cracking *within* hybrid EDs). Any
  per-flag cracking note must ride on this, not on an adjacency-chain claim.
