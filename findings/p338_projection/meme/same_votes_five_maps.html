Alberta's election maps

Same votes. Five maps.

Put today's polls (UCP 48%, NDP 43%) on each map. Who wins?
Now make it a tie. Same share of the vote for both parties:
In a tie, only one map hands the UCP a majority.
Why do most maps go NDP in a tie? UCP voters are packed into big rural wins; NDP voters win city seats by less. The dissenting map flips that.
Where the numbers come from: 338Canada's poll average for each riding (October 19, 2026), placed on each map using where Albertans voted in 2023. Added up riding by riding it is 47.6% to 43.4%. Red Deer-North is an exact tie. The panel's maps were redrawn from its report; the official files aren't public yet. Polls can be wrong, so we ran 5,000 simulated elections: the dissenting commissioners' map still favours the UCP most, however we set them up.
